## 部署与维护边界

标准只读 Compose 仍不提供 Build Agent 的 Docker 执行通道。本次提供的是已有宿主执行方式的明确支持和前置检查，没有引入新的分布式构建 worker，也没有给 Web 容器挂载 Docker socket。操作步骤见 [宿主部署指南](BUILD_AGENT_HOST_DEPLOYMENT.md)。

产物清理采用离线维护方式，不会后台自动删文件：停止全部 worker 后先运行 `python -m lima.build_artifact_cleanup` 查看候选，确认后运行 `python -m lima.build_artifact_cleanup --apply --workers-stopped`。该确认是运维前置条件，命令不会假定自己能探测所有分布式 worker。

生产构建规划器仍是确定性的 CMake 流程。本次修复没有接入通用 LLM 构建规划器，也没有改变完整 Audit → Mining → Repair 平台仍在建设中的定位。
