## 2. 当前实现层次

### 第一层：确定性仓库画像

- [ ] 只读识别项目语言、框架线索、项目类型、入口、配置、依赖清单、测试和组件结构。
- [ ] 对跳过、无法识别和预算不足的内容生成明确的 coverage gap。
- [ ] 保证路径为仓库相对路径，不泄漏主机路径、源码全文或秘密。

### 第二层：安全架构模型

- [ ] 基于现有 workspace 和 Python 静态事实识别外部输入、敏感操作、信任边界和关键调用关系。
- [ ] 保留动态导入、歧义调用和解析失败，不把“未看到”表达为“没有风险”。
- [ ] 对 monorepo 按组件输出画像和关系。

### 第三层：优先级与降级

- [ ] 只允许语义能力对确定性候选补充说明和排序，不得创造或删除静态事实。
- [ ] 模型关闭、超时或返回错误时，确定性画像仍能完整产出。
- [ ] 相同仓库快照、策略和预算产生可重放的结果。
