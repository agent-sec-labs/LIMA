# [Competition][E07][独立工具] 导出白名单环境清单，不读取凭证或完整环境

## 目标和适合的执行者
给实验和交付件附一份可复核的环境身份，减少本机环境无法还原的问题。需要 Python/子进程/JSON，预计 1–2 天；不涉及漏洞判断。

## 文件所有权
仅允许新增 scripts/export_competition_environment.py、lima/competition_environment.py、tests/test_competition_environment.py、docs/competition/tools/environment.md。
只读参考 pyproject.toml、cxx_analyzer/Dockerfile、现有 Git/子进程调用风格；不修改依赖或导入设置初始化流程。

## 输入输出合同
入口：python scripts/export_competition_environment.py --repository <lima-checkout> --run-label <label> --output <new-environment.json> [--container <exact-id-or-name>] [--model-label <operator-label>]。
1. 默认仅收集 schema_version=1、run_label、UTC 时间、OS 类型/版本、架构、逻辑 CPU 数、当前 Python 版本、源码 commit 和 dirty（含未跟踪文件）状态。内存总量无法仅靠现有依赖可靠获取则 null+reason，不为此安装库。git 返回异常要 unknown，不把不可读当 clean。
2. 工具版本只用代码内固定工具名与固定 --version 参数白名单、argv+shell=False、有界超时和输出；不存在为 null+原因，不执行用户传来的“版本命令”。标明采自宿主；不能把宿主 clang 版本冒充 Sidecar clang。
3. Docker inspect 仅显式 --container 后只读查询该容器，投影 image id、镜像引用和 CPU/memory/PID 限额；不保存全量 inspect（含 Env/Mounts），不 docker exec、不拉取/构建/重启、不探测其他容器。容器内部工具版本未采集就 unknown。
4. model-label 为操作者提供的标签，标 operator-declared，不读取 key、不调用供应商、不声称后端版本已验证；如需额外预算值，仅接受文档列出的显式数值参数，不枚举环境变量。
5. 不读 .env/config.toml/credential，不转储 os.environ、sys.path、完整命令行、用户名、机器名、绝对工作目录；异常输出只给类别，不回显原始 stderr。镜像引用/标签如含凭证、URL 参数或异常控制字符则拒绝，不收集任意输入原文。
6. 输出新 JSON，0=清单已生成（每项可 unknown），2=必需的输入/仓库身份无法读取，3=参数/输出错误。可选 Docker 或工具不可用保留诊断不伪造值。明确这份环境清单不是锁定全部依赖、不是健康检查。
