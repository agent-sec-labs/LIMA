## Proposed solution（Codex 实施）
1. 新增 smoke-test 包装脚本 `scripts/smoke_clean_deploy.py`：在专用 Compose project + 独立测试数据目录中，按 `deploy/competition/README.md` 的步骤执行启动、服务健康检查、Sidecar 能力探测、退出清理，输出结构化记录（环境、逐条命令、日志、退出码、结论）。
2. 检查项（逐项落记录）：
   - 干净目录/干净机器按手册部署成功；
   - **无密钥不误调用付费模型**：`.env` 缺失或凭证留空时，能力按文档声明显式禁用/提示，而不是崩溃或静默调用付费端点；
   - 示例任务跑通且预期配置错误（缺必填项）有明确错误提示；
   - 输出目录正确创建，无越权写入；
   - 生成物与配置中**不存在维护者本机绝对路径**（对输出做路径扫描并记录结果）；
   - 端口冲突、依赖缺失有可操作诊断。
3. 失败处理：发现的问题按"阻塞冻结 / 可推迟"分两列记录，阻塞项各开一个小 Issue 修复后复跑（不重开大任务）；复跑结果追加记录，不覆盖。
4. 不使用维护者现有数据库、卷或管理员账号；清理只针对本任务创建的资源；不调用真实模型。
