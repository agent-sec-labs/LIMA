# [Competition][E11] DEMO 彩排与演示视频（附实施与人工验收清单）

## Problem to solve
提交材料需要 DEMO 视频。已有 DEMO 脚本（`docs/competition/DEMO脚本.md`，#285 锚点）与彩排记录，缺面向参赛版本的可重复彩排和成品视频。本 Issue 先立任务书（10-15 前）；**录制在 10-20 代码冻结之后**按彩排脚本进行，使用与 release 一致的 SHA/环境。

## Proposed solution（实施）
1. 彩排：冻结 SHA 的检出 + E08 通过的部署环境上，按 DEMO 脚本完整走一遍；每步核对预期输出与实际输出，偏差记录并回报（不改脚本自欺）。脚本如需因 V02 战果/口径变化调整，先经维护者确认再改。
2. 录制内容（按脚本章节）：环境检查、任务提交、进度观察、证据等级展示、真实 PoC 记录、修复对照、影响报告、导出操作。
3. 真实性标注（硬性）：画面/字幕对**真实运行、历史记录回放、Fake 演示**三类分别标注；长耗时步骤用已封存真实记录讲解时必须注明"历史回放"；不得把 Fake 演示当真实性能或漏洞成果展示。
4. 隐私与合规：画面无密钥、无维护者本机路径/个人信息、无未经批准的漏洞材料；正文与画面符合官方匿名要求（不出现学院、导师信息）。
5. 讲解词中的漏洞定性与评分主张先送维护者审批（脚本级审核，一次审完整版），批准后录制；重录只改画面错误，不擅改主张。
