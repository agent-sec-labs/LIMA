# V07 性能采样手工兜底模板（冻结版 v1）

冻结日期：2026-10-17。触发条件：若 #292 性能采集包装器在 10-18 交付闸门
前未合并交付，V07 性能实测按本模板执行；若 #292 按期交付，则优先使用
#292 采集器，本模板仅作交叉核对用途。两者不混用于同一记录（measurement_source
字段区分）。

## 1. 诚实规则（先于一切）

1. 任何未采到、未测、不适用的字段一律记 `null` 并在 `gaps` 写原因，
   **绝不写 0**。
2. 采样值是**采样峰值**，不是绝对峰值（采样间隔之间的尖峰不可见）；
   所有对外表述必须带"采样"限定词。
3. `ru_maxrss(RUSAGE_CHILDREN)` 语义 = 已等待子进程中**最大单进程** RSS，
   不是进程树总和；docker stats 的容器内存 = 容器内全部进程之和（与前者
   口径不同，分列不混算）。
4. 中止/超时/失败的批次照常成档：记录已完成范围、资源采样、coverage gap
   和中止原因；不得因中止而丢弃已采数据。
5. 每条记录必须附完整命令 argv（脱敏后）与原始采样文件名，可复算。

## 3. 采样命令（冻结版）

### 3.1 容器资源采样循环（宿主侧，Git Bash；测量开始前启动，结束后 Ctrl+C）

```bash
OUT="perf_samples_$(date +%Y%m%d_%H%M%S).csv"
echo "timestamp;container;mem_usage;mem_percent;cpu_percent;net_io;block_io;pids" > "$OUT"
while true; do
  printf '%s;%s\n' "$(date -u +%Y-%m-%dT%H:%M:%SZ)" \
    "$(docker stats --no-stream --format '{{.Name}};{{.MemUsage}};{{.MemPerc}};{{.CPUPerc}};{{.NetIO}};{{.BlockIO}};{{.PIDs}}' | grep -E 'chain-probe|cxx-analyzer' | tr '\n' '|')" >> "$OUT"
  sleep 5
done
```

PowerShell 等价版：

```powershell
$out = "perf_samples_$(Get-Date -Format yyyyMMdd_HHmmss).csv"
"timestamp;container;mem_usage;mem_percent;cpu_percent" | Out-File $out -Encoding utf8
while ($true) {
  $rows = docker stats --no-stream --format '{{.Name}};{{.MemUsage}};{{.MemPerc}};{{.CPUPerc}}' |
    Select-String 'chain-probe|cxx-analyzer'
  foreach ($r in $rows) {
    "$([DateTime]::UtcNow.ToString(`"yyyy-MM-ddTHH:mm:ssZ`"));$r" | Out-File $out -Append -Encoding utf8
  }
  Start-Sleep -Seconds 5
}
```

结束判读：对每容器取 `mem_usage` 数值的最大者为 `sampled_peak_mem_bytes`
（注意 docker stats 输出是 "用量 / 限额" 两段，取前段；MiB/GiB 换算成字节）。

### 3.2 墙钟 + 退出码 + 子进程峰值 RSS（容器内 python 包装器）

容器内无 `/usr/bin/time`，用 python `resource` 模块包装被测命令
（存为 `/tmp/measure.py` 后调用）：

```python
import json, resource, subprocess, sys, time
cmd = sys.argv[1:]
t0 = time.monotonic()
rc = subprocess.call(cmd)
elapsed = time.monotonic() - t0
peak_kb = resource.getrusage(resource.RUSAGE_CHILDREN).ru_maxrss
print(json.dumps({
    "wall_time_seconds": round(elapsed, 3),
    "command_exit_code": rc,
    "host_child_peak_rss_bytes": peak_kb * 1024,
}))
sys.exit(rc)
```

调用形态：`python /tmp/measure.py <被测命令完整 argv>`（argv 原样记进记录）。
Ctrl+C 时包装器与被测命令一并终止，`wall_time_seconds` 作废本次（在 gaps
注明"中断"），容器采样 CSV 保留已采部分。

### 3.3 覆盖率数据

从被测运行自身的产物取（bundle `summary.json` / 平台输出的文件数、字节数、
TU 数、完成窗口数），不自造口径；取不到的字段进 `gaps`。

  缺口，不从四目标外推。
