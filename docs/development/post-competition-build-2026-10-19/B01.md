## 目标与范围

将现有 CLI 执行器接入持久化后台任务，浏览器关闭后构建继续；前端和模型服务不直接持有 Docker socket。

- API 支持创建/查询构建任务、阶段日志、取消、基于新attempt的重试、产物下载；复用现有认证、租户、存储和队列。
- 独立构建Worker调用现有执行器，记录源码提交、配方/执行器哈希、镜像ID、功能变体、容器/卷身份、预算与逐步退出码。
- 明确 queued、运行阶段、completed、failed、cancelled、unsupported/needs-assistance 等状态及其向现有Task状态的映射，避免双重状态漂移。
- 原始仓库只读；仅清理本任务登记的容器/卷/临时目录；新attempt不覆盖旧日志；支持Worker异常后的状态对账。
