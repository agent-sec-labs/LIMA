## Task 9: 工具证据 binder + Evidence Broker

复审修正：新增**确定性 binder**（现有 `bind_tool_evidence` 是 CWE/path/symbol/宽松行号 + 裸 candidate_id 键，不满足精确身份绑定），再建 Broker 三态。

**Files:**

- Create: `lima/uaf_broker.py`（`broker_verdict(identity: CandidateIdentity, producer) -> support|contradict|no-evidence` + gap 附注）
- Create: `tests/test_uaf_evidence_binder.py`、`tests/test_uaf_broker.py`
- Modify: `lima/cxx_memory.py`（仅为非破坏性导出所需 helper，非 UAF 行为零变化）

**binder 规则（冻结）：**

- Semgrep/Clang Finding：`canonical_path` 精确相等 **且** finding 行号落入候选 `release_range` 或 `use_range`（闭区间，无 ±N 容差）**且**（symbol 为空或等于 `function_usr` 末段）→ 可绑定；否则 `binding_gap` + no-evidence。
